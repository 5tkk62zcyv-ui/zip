# MVP 임시 인증

TaxiTaShare의 현재 로그인은 학번과 가입 시 입력한 이름의 정확한 일치만
확인한다. 비밀번호, 학교 이메일 인증 또는 학생증 인증을 추가하지 않는
MVP 임시 방식이다.

학번과 이름은 비밀정보가 아니므로 계정 가장을 막는 강한 인증 수단이
아니다. 실제 서비스 출시 전 별도의 인증 정책과 계정 복구, 세션 탈취
대응을 설계해야 한다. 현재 구현은 이 위험을 사용자 화면에도 안내한다.

세션은 무작위 토큰의 SHA-256 해시만 DB에 저장하고 원문 토큰은 HttpOnly,
SameSite=Lax, Production Secure 쿠키로 보관한다. 로그아웃 시 DB 세션을
폐기한 다음 쿠키를 삭제한다.
